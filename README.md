Vesper Aura — Interactive Particle Simulator

An atmospheric digital experience built around motion and visual interaction.

Vesper Aura is an interactive sensory particle-effects web application styled as a dark-luxury atmosphere console.

The project explores how particle animation and interface design can create an immersive web experience.

The Concept

Rather than building another conventional dashboard, Vesper Aura focuses on the visual experience itself: an atmospheric interface where particle effects become the central element.

Project Highlights

- Interactive particle-effects experience
- Sensory visual interactions
- Dark-luxury interface direction
- Particle animation infrastructure

Technology Stack

- React
- TypeScript
- Vite
- Tailwind CSS

Design Direction

A dark-luxury atmosphere console, designed to make the particle experience feel immersive and visually distinctive.

Project Goal

Explore interactive visual experiences through frontend development, motion and particle effects.

Status

An interactive particle-simulator web application.
